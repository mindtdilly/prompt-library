# Prompt Library

See the pattern. Copy the brief.

84 stack-agnostic UI component prompts (Marsaze-style), with search, categories, and one-click copy for coding agents.

## Netlify

Import this repo in Netlify (Build command `npm run build`, publish `dist`). Already authorized Netlify↔GitHub is enough — no personal access token required for that path.

## Run locally

```bash
npm install
npm run dev
```
